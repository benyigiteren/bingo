API & MCP Dokümantasyonu

Bingo; REST API ve Model Context Protocol (MCP) üzerinden Claude, Cursor, Gemini, terminal betikleri ve yapay zeka ajanları ile tam uyumlu çalışır.

1. SINIF DESTEK

Model Context Protocol (MCP) Uç Noktası

Bingo, standart /mcp rotası üzerinden HTTP SSE (Server-Sent Events) ve doğrudan JSON-RPC 2.0 akışlarını destekler. Cursor ve Claude Desktop gibi MCP istemcileri bu adrese bağlanarak dosya yükleme, okuma, arama ve imha işlemlerini otonom olarak gerçekleştirebilir. 

{{ .BaseURL }}/mcp?api_key=bg_api_anahtariniz
Yerel Terminal / CLI Modu: bingo mcp --api-key="bg_api_anahtariniz"

Kimlik Doğrulama (Authentication)

Tüm REST ve MCP istekleri kişisel API anahtarınızı gerektirir:

HTTP Header
X-API-Key: bg_...
Bearer Token
Authorization: Bearer bg_...
URL Query (SSE & Tools için)
?api_key=bg_...
POST /api/upload

Dosya, görsel veya metin/kod yükler. İsteğe bağlı olarak ttl, is_burn ve password parametrelerini kabul eder.

1. JSON ile Kod / Metin Yükleme (Önerilen)

curl -X POST \
  -H "Content-Type: application/json" \
  -H "X-API-Key: bg_api_anahtariniz" \
  -d '{
    "text": "package main\n\nfunc main() {}",
    "filename": "server.go",
    "ttl": "1d",
    "is_burn": false,
    "password": "secret_pass_optional"
  }' \
  {{ .BaseURL }}/api/upload

2. Multipart / Dosya Yükleme

curl -X POST \
  -H "X-API-Key: bg_api_anahtariniz" \
  -F "file=@resim.png" \
  -F "ttl=1h" \
  {{ .BaseURL }}/api/upload

3. Pipe / Akış Yükleme

docker logs app | curl -X POST \
  -H "Content-Type: text/plain" \
  -H "X-API-Key: bg_api_anahtariniz" \
  -H "X-TTL: 10m" \
  --data-binary @- \
  {{ .BaseURL }}/api/upload
{{ end }}
