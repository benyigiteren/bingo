API & MCP Referansı

REST API ve Model Context Protocol (MCP) entegrasyon kılavuzu

Model Context Protocol (MCP)

Claude Desktop, Cursor, Gemini ve yerel terminal ajanları için yerel JSON-RPC 2.0 uç noktası:

{{ .BaseURL }}/mcp?api_key=api_anahtariniz

Kimlik Doğrulama (Authentication)

API anahtarınızı aşağıdaki yöntemlerden biriyle sağlayabilirsiniz:

Header: X-API-Key: bg_... Header: Authorization: Bearer bg_... Sorgu: ?api_key=bg_...

POST /api/upload

Metin, kod veya dosya yüklemek için JSON formatında POST isteği gönderin (ttl, is_burn ve password parametreleri isteğe bağlıdır): 

curl -X POST \
  -H "Content-Type: application/json" \
  -H "X-API-Key: api_anahtariniz" \
  -d '{"text": "console.log(1)", "filename": "app.js", "ttl": "1d"}' \
  {{ .BaseURL }}/api/upload
