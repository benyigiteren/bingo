Model Context Protocol (MCP)

Native JSON-RPC 2.0 endpoint for Claude Desktop, Cursor, Gemini, and local terminal agents.

{{ .BaseURL }}/mcp?api_key=your_api_key
Authentication

Provide your API key via HTTP headers or URL query parameter:

Header: X-API-Key: bg_... Header: Authorization: Bearer bg_... Query: ?api_key=bg_...
POST /api/upload

Uploads raw text, code, or binary files with optional ttl, is_burn, and password parameters. 

curl -X POST \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_api_key" \
  -d '{"text": "console.log(1)", "filename": "app.js", "ttl": "1d"}' \
  {{ .BaseURL }}/api/upload
